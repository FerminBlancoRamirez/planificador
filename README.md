## Inicializar el proyecto
```
npm init
```

## Descargar una dependencia de desarrollo(vite)
```
npm i -D vite
```

## Ejecutar una aplicacion en modo desarrollo
```
npm run dev
```

## Descargar una dependencia de produccion(dayjs)
```
npm i dayjs
```

## Arrancar la aplicacion en modo produccion
```
npm run preview
```

## Desplegar en netlify usando la CLI
```
npm i -g netlify-cli

netlify login

netlify init
```
